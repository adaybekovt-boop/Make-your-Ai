# Создай свой ИИ — NEURON

Браузерная одиночная игра об AI-компании. Текущая версия — прототип Фазы 0, не полная игра.

## Запуск

Требуется Node.js 22.12+ (рекомендуется ветка 22 LTS) и npm.

Распакуйте архив, откройте терминал в папке `create-your-ai` и выполните:

```sh
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite в терминале (обычно http://127.0.0.1:5173/).

## Проверки и production-сборка

```sh
npm test
npm run typecheck
npm run build
npm run preview
```

`dist/` содержит готовую сборку. Её можно разместить на статическом HTTP-сервере. Не открывайте `dist/index.html` через `file://`: приложению нужен HTTP-сервер.

## Что реализовано

- Пять полигональных локаций на карте PixiJS.
- Покупка площадок, установка и продажа одного типа GPU-серверов.
- Доходы, расходы, локальные энергетические лимиты и троттлинг.
- Пауза, скорость 1×/3× и обучение базовым действиям.
- Сохранения в IndexedDB с версионированием.
- Цены в игровых долларах США (USD), без реальных платежей.

Фазы 1–3 не реализованы. Полная GUI-приёмка Фазы 0 пока не завершена: подробности, подтверждённые сценарии и ограничения проверки находятся в [GUI_TEST_REPORT.md](GUI_TEST_REPORT.md). Снимки расположены в `gui-test-screenshots/`.

## Структура

- `src/systems/` — чистая игровая логика и тесты формул.
- `src/store/` — состояние Zustand и таймер симуляции.
- `src/render/` — рендер карты PixiJS.
- `src/ui/` — React-компоненты и стили.
- `src/persistence/` — IndexedDB, проверка и миграция сохранений.
- `src/shared/` — общее форматирование валюты.

## Сохранения и состав архива

Сохранения живут в браузере, привязаны к адресу сайта, включая порт, и не входят в ZIP. Для продолжения своей компании используйте тот же браузер и адрес. В скрытой вкладке и при закрытой игре время не идёт.

Архив содержит исходники, конфигурацию, `package-lock.json`, сборку и материалы тестирования. `node_modules`, временные файлы и приватные настройки исключены. Команда `npm ci` установит зависимости из lock-файла; для неё нужен доступ к npm-реестру.
