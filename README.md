# Создай свой ИИ — NEURON

Браузерная одиночная игра об AI-компании: серверные площадки, оборудование, обучение модели и рынок.

## Запуск

Требуется Node.js 22.12+ и npm.

```sh
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite в терминале.

## Закупка оборудования

Войдите в купленную локацию и нажмите на пустую ячейку. Модальное окно позволяет заказать комплект «шасси + чип» или оборудование отдельно, выбрать канал закупки и количество.

- Официальный канал: базовая цена ×1.6; без дополнительного заводского брака.
- Серый импорт: базовая цена ×1.1; 8% брака на каждую единицу при монтаже.
- Оптовая скидка на одинаковое оборудование в одном заказе: 5% за каждую единицу после первой, максимум 20%.
- Вся оплата списывается при заказе. Комплект оплачивается целиком или не оформляется.
- После доставки оборудование поступает на склад выбранной локации. Монтаж выполняется вручную в том же окне, без повторной оплаты.
- Статус «в пути», таймер и склад доступны в модалке ячейки. Доставка идёт по игровому времени и останавливается на паузе.
- Апгрейд требует совместимой стойки и оплаты только нового чипа. Старый исправный чип возвращается на склад. При продаже или отказе чипа стойка остаётся.
- Брак серого импорта и отказ при разгоне используют общий механизм утилизации: потеря неисправного оборудования и расходы 15% его базовой цены.

| Шасси | Базовая цена | Поддержка | Модификаторы |
| --- | ---: | --- | --- |
| Базовая стойка | $1 000 | Terra T1, Titan X9 | — |
| Стойка с охлаждением | $5 000 | + Helios HC | Риск отказа чипа −15% |
| Энтерпрайз-стойка | $20 000 | + Zenith Z1 | Риск отказа −25%, вычисления +10% |

| Чип | Официальная доставка | Серый импорт |
| --- | ---: | ---: |
| Terra T1 | 6 ч | 2 ч |
| Titan X9 | 8 ч | 2 ч |
| Helios HC | 10 ч | 3 ч |
| Zenith Z1 | 12 ч | 4 ч |

Для доставки шасси сохранены сроки из начатой реализации: базовая стойка — 6/2 ч, охлаждаемая — 8/3 ч, энтерпрайз — 12/4 ч (официальный/серый канал).

## Проверки и сборка

```sh
npm test
npm run typecheck
npm run build
npm run preview
```

`dist/` содержит сборку для статического HTTP-сервера. Не открывайте её через `file://`.

## Структура

- `src/systems/` — игровая логика, закупки, доставка, монтаж и тесты.
- `src/store/` — состояние Zustand и таймер симуляции.
- `src/render/` — карта и интерьер Three.js.
- `src/ui/` — React-компоненты и стили.
- `src/persistence/` — IndexedDB, проверка и миграция сохранений.

Сохранения привязаны к браузеру и адресу сайта, включая порт. В скрытой вкладке и при закрытой игре время не идёт. Сохраняются заказы, остатки склада, происхождение серого оборудования и установленные стойки. Старые сохранения дополняются новыми полями.

Исторический отчёт о проверке раннего прототипа — `GUI_TEST_REPORT.md`; он не описывает текущий сценарий закупки. Актуальная проверка — `PROCUREMENT_TEST_REPORT.md`.
