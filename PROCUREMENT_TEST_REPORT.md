# Проверка закупки оборудования

Дата: 2026-09-06.

## Автоматические проверки

- `npm test`: 210 тестов, 19 файлов.
- `npm run build`: TypeScript и production-сборка Vite.
- В тестах проверены цены обоих каналов, скидки и их предел, сроки доставки всех четырёх чипов, атомарная оплата комплекта, отсутствие повторного списания при доставке и монтаже.
- Проверены граница 8% брака, отсутствие дополнительного брака официала, единые последствия с отказом оборудования, сохранение исправного старого чипа при неудачном апгрейде и происхождения складских остатков после загрузки.
- Проверены совместимость стоек, лимит энергии, сохранение флагманского чипа, отсутствие потери склада при запрещённом монтаже, корректность заказов в сохранениях и миграция старых сохранений.

## Проверка в браузере

Проверено на отдельном локальном адресе `http://127.0.0.1:5176/` через интерфейс игры.

1. Куплен гараж, выполнен вход в интерьер. Клик по пустой ячейке открыл модалку закупки, сервер не установлен.
2. Выбраны две базовые стойки и два Terra T1 через серый канал. Модалка показала скидку 5%, сумму $6 270 ($2 090 за стойки и $4 180 за чипы), доставку 2 игровых часа.
3. После оплаты отображались два заказа «в пути» с уменьшающимся таймером. Ячейка оставалась свободной, склад — пустым.
4. На скорости 3× дождались доставки. На складе появились по две единицы с пометкой серого импорта; автоматического монтажа не было.
5. Вручную смонтированы стойка и чип. Остатки уменьшились до одной единицы каждого вида. В сетке показаны 1/9 занятых ячеек, Terra T1, 2/3 кВт и прибыль $754/ч.
6. После монтажа модалка предложила совместимый апгрейд Titan X9 за $9 600 по официальному каналу — только стоимость чипа.
7. Игра поставлена на паузу, сохранена и перезагружена. Капитал $4 209, время 14:14, сервер и складские остатки серого оборудования восстановлены.
8. Ошибок JavaScript в консоли браузера не обнаружено. Модалка и её прокрутка проверены визуально при размере окна 1280×720.

Фактическая доставка и монтаж апгрейда, детерминированные отказы и остальные классы оборудования проверены юнит-тестами; полный цикл каждого из них в браузере не повторялся. Vite сообщает о крупном чанке Three.js — сборка завершается успешно.
